# Starlink Tenderkaart

Kaart van Europa met aanbestedingen voor Starlink en satellietinternet uit TED (Tenders Electronic Daily).

- De site staat op GitHub Pages en is zonder inloggen te bekijken.
- Elke werkdag haalt GitHub automatisch de nieuwste tenders op (`.github/workflows/update.yml` → `scripts/fetch-ted.mjs`) en zet ze in `data/tenders.json`.
- Handmatig verversen: tabblad **Actions** → **Tenders ophalen bij TED** → **Run workflow**.
